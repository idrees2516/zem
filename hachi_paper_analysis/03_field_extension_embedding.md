# Field Extension Embedding - Detailed Requirements

## 1. Subfield Identification (Lemma 5)

### 1.1 Theorem Statement
```
Let q ≡ 5 (mod 8) and k ≥ 1 divide d/2
Let H := ⟨σ_{-1}, σ_{4k+1}⟩ ⊆ Aut(R)
Then R_q^H ≅ F_{q^k} (isomorphic as fields)
```

### 1.2 Subgroup Structure
**Requirements**:
- H generated by two automorphisms:
  - σ_{-1}: X ↦ X^{-1} = -X^{d-1} (complex conjugation)
  - σ_{4k+1}: X ↦ X^{4k+1}
- |H| = 2k (order of subgroup)
- H is closed under composition

### 1.3 Fixed Element Structure
**Requirements**:
- Elements of R_q^H have form:
```
a = a_0 + ∑_{j=1}^{k-1} a_{k-j} · (X^{d·(k-j)/(2k)} - X^{d·(k+j)/(2k)})
```
- k degrees of freedom: a_0, a_1, ..., a_{k-1} ∈ Z_q
- |R_q^H| = q^k
- Closed under addition and multiplication

### 1.4 Field Properties
**Requirements**:
- R_q^H is subset of elements stable under σ_{-1}
- σ_{-1}-stable elements form a field (Lyubashevsky-Nguyen-Plançon)
- R_q^H inherits field structure
- Isomorphism to F_{q^k} is constructive

## 2. Inner Product Embedding (Theorem 2)

### 2.1 Main Theorem Statement
```
Let k divide d/2, H := ⟨σ_{-1}, σ_{4k+1}⟩
Define ψ: (R_q^H)^{d/k} → R_q by:
ψ(a_0,...,a_{d/k-1}) := ∑_{i=0}^{d/(2k)-1} a_i·X^i + X^{d/2}·∑_{i=0}^{d/(2k)-1} a_{d/(2k)+i}·X^i

Then:
1. ψ is bijection
2. For any a, b ∈ (R_q^H)^{d/k}:
   Tr_H(ψ(a)·σ_{-1}(ψ(b))) = (d/k)·⟨a,b⟩
```

### 2.2 Bijection Property

#### Injectivity Proof Requirements
**Step 1**: Expand ψ(a) using fixed element structure:
```
ψ(a) = ∑_{i=0}^{d/(2k)-1} [X^i·a_{i,0} + X^{d/2+i}·a_{d/(2k)+i,0}]
     + ∑_{j=1}^{k-1} a_{i,k-j}·(X^{d·(k-j)/(2k)+i} - X^{d·(k+j)/(2k)+i})
     + ∑_{j=1}^{k-1} a_{d/(2k)+i,k-j}·(X^{d·(d/(2k)-j)/(2k)+i} - X^{d·(d/(2k)+j)/(2k)+i})
```

**Step 2**: If ψ(a) = 0, analyze coefficients:
- Coefficient of X^u for 0 ≤ u < d/(2k): equals a_{u,0}
- Coefficient of X^{d/(2k)+u}: equals a_{d/(2k)+u,0}
- Therefore a_{u,0} = a_{d/(2k)+u,0} = 0

**Step 3**: For 1 ≤ u < k and 0 ≤ v < d/(2k):
- Coefficient of X^{d·u/(2k)+v}: equals a_{v,u} + a_{d/(2k)+v,k-u}
- Coefficient of X^{d·(k+u)/(2k)+v}: equals -a_{v,k-u} + a_{d/(2k)+v,u}
- System implies: a_{d/(2k)+v,u} = a_{v,k-u} = -a_{d/(2k)+v,u}
- Therefore a_{d/(2k)+v,u} = a_{v,u} = 0

**Step 4**: Conclude a = 0, proving injectivity

#### Surjectivity
**Requirements**:
- Domain and codomain have same size: q^d
- Injection implies surjection
- Therefore ψ is bijection

### 2.3 Inner Product Property

#### Auxiliary Claims

**Claim 1**: Subgroup Structure
```
⟨4k+1⟩ = {(4k)·α + 1 : 0 ≤ α ≤ d/(2k) - 1} in Z_{2d}^×
```
**Proof Requirements**:
- Show (4k+1)^i ≡ (4k)·i + 1 (mod 2d) for all i
- Order of 4k+1 is d/(2k)
- Uses: 4k divides 2d

**Claim 2**: Trace of Non-Multiples
```
For i not divisible by d/(2k):
Tr_H(X^i) = 0
```
**Proof Requirements**:
```
Tr_H(X^i) = ∑_{h∈⟨-1,4k+1⟩} X^{h·i}
          = ∑_{h∈⟨4k+1⟩} (X^{h·i} + X^{-h·i})
          = ∑_{α=0}^{d/(2k)-1} (X^{((4k)·α+1)·i} + X^{-((4k)·α+1)·i})
          = X^i · (X^{4ki})^{d/(2k)} - 1)/(X^{4ki} - 1) + X^{-i} · (X^{-4ki})^{d/(2k)} - 1)/(X^{-4ki} - 1)
```
- Since 4ki not divisible by 2d: X^{4ki} ≠ 1
- Numerators vanish, denominators don't
- Therefore Tr_H(X^i) = 0

**Claim 3**: Trace of X^{d/2}
```
Tr_H(X^{d/2}) = 0
```
**Proof Requirements**:
```
Tr_H(X^{d/2}) = ∑_{α=0}^{d/(2k)-1} (X^{((4k)·α+1)·d/2} + X^{-((4k)·α+1)·d/2})
              = ∑_{α=0}^{d/(2k)-1} (X^{d/2} + X^{-d/2})
              = ∑_{α=0}^{d/(2k)-1} (X^{d/2} - X^{d/2}) = 0
```

#### Main Inner Product Calculation
**Requirements**:
```
ψ(a)·σ_{-1}(ψ(b)) = [∑_{i=0}^{d/(2k)-1} a_i·X^i + X^{d/2}·∑_{i=0}^{d/(2k)-1} a_{d/(2k)+i}·X^i]
                    · [∑_{j=0}^{d/(2k)-1} b_j·X^{-j} + X^{d/2}·∑_{j=0}^{d/(2k)-1} b_{d/(2k)+j}·X^{-j}]
```

Expanding:
```
= ∑_{i,j} a_i·b_j·X^{i-j} + ∑_{i,j} a_{d/(2k)+i}·b_{d/(2k)+j}·X^{i-j}
  + X^{d/2}·[∑_{i,j} a_{d/(2k)+i}·b_j·X^{i-j} - ∑_{i,j} a_i·b_{d/(2k)+j}·X^{i-j}]
```

Applying Tr_H:
- For i ≠ j: Tr_H(X^{i-j}) = 0 (by Claim 2)
- For i = j: Tr_H(X^0) = Tr_H(1) = 2k
- Tr_H(X^{d/2}·...) = 0 (by Claim 3)

Therefore:
```
Tr_H(ψ(a)·σ_{-1}(ψ(b))) = ∑_{i=0}^{d/(2k)-1} (a_i·b_i + a_{d/(2k)+i}·b_{d/(2k)+i})·2k
                          = 2k · ∑_{i=0}^{d/k-1} a_i·b_i
                          = (d/k) · ⟨a,b⟩
```

### 2.4 Norm Preservation (Lemma 6)

**Statement**:
```
For a ∈ (R_q^H)^{d/k} with ||a||_∞ ≤ β:
||ψ(a)||_∞ ≤ 2β
```

**Proof Requirements**:
- From explicit formula in Equation (9)
- Some coefficients of ψ(a) are sums of two coefficients of a
- Each coefficient of a has norm ≤ β
- Sum of two such coefficients has norm ≤ 2β
- Therefore ||ψ(a)||_∞ ≤ 2β

## 3. Generic Transformation (Section 3.1)

### 3.1 Problem Setup
**Input**: Polynomial evaluation claim over F_{q^k}
```
f(x_1,...,x_ℓ) = y
```
Where:
- f ∈ F_{q^k}^{≤1}[X_1,...,X_ℓ]
- Coefficients (f_ι)_{ι∈{0,1}^ℓ} ∈ F_{q^k}
- Evaluation point (x_1,...,x_ℓ) ∈ F_{q^k}^ℓ
- Image y ∈ F_{q^k}

**Output**: Equivalent relation over R_q

### 3.2 Transformation Steps

**Step 1**: Rewrite evaluation as nested sum
```
y = ∑_{i∈{0,1}^{ℓ-α+κ}} x_1^{i_1}·...·x_{ℓ-α+κ}^{i_{ℓ-α+κ}}
    · [∑_{j∈{0,1}^{α-κ}} f_{i||j}·x_{ℓ-α+κ+1}^{j_1}·...·x_ℓ^{j_{α-κ}}]
```
Where:
- α = log_2(d)
- κ = log_2(k)
- ℓ - α + κ outer variables
- α - κ inner variables

**Step 2**: Define ring elements
```
For each i ∈ {0,1}^{ℓ-α+κ}:
F_i := ψ((f_{i||j})_{j∈{0,1}^{α-κ}}) ∈ R_q

Also define:
v := ψ((x_{ℓ-α+κ+1}^{j_1}·...·x_ℓ^{j_{α-κ}})_{j∈{0,1}^{α-κ}}) ∈ R_q
```

**Step 3**: Apply trace map
```
Since y ∈ R_q^H and Tr_H(y) = 2k·y:
(d/k)·y = Tr_H(∑_{i∈{0,1}^{ℓ-α+κ}} x_1^{i_1}·...·x_{ℓ-α+κ}^{i_{ℓ-α+κ}}·F_i·σ_{-1}(v))
```

**Step 4**: Define witness polynomial
```
Y := ∑_{i∈{0,1}^{ℓ-α+κ}} x_1^{i_1}·...·x_{ℓ-α+κ}^{i_{ℓ-α+κ}}·F_i ∈ R_q
```

**Step 5**: Verification equation
```
Verifier checks: Tr_H(Y·σ_{-1}(v)) = (d/k)·y
```

**Step 6**: Prove well-formedness
- Y is evaluation of (ℓ-α+κ)-variate polynomial F := (F_i)_i over R_q
- Reduces to polynomial evaluation over R_q
- Can apply recursive protocol

### 3.3 Communication Cost
**Requirements**:
- Prover sends: Y ∈ R_q (d·log(q) bits)
- Verifier computes: v, (d/k)·y
- Verifier checks: trace equation
- Total: d·log(q) bits for this step

## 4. Optimized Transformation for Base Field (Section 3.2)

### 4.1 Problem Setup
**Input**: Special case where:
- Polynomial f ∈ F_q^{≤1}[X_1,...,X_ℓ] (coefficients over base field)
- Evaluation point (x_1,...,x_ℓ) ∈ F_{q^k}^ℓ (over extension)
- Image y ∈ F_{q^k}

**Goal**: Reduce to (ℓ-α)-variate polynomial over R_q (better than ℓ-α+κ)

### 4.2 Transformation Steps

**Step 1**: Rewrite as partial evaluations
```
y = ∑_{i∈{0,1}^κ} x_1^{i_1}·...·x_κ^{i_κ}
    · [∑_{j∈{0,1}^{ℓ-κ}} f_{i||j}·x_{κ+1}^{j_1}·...·x_ℓ^{j_{ℓ-κ}}]
```
Define:
```
y_i := ∑_{j∈{0,1}^{ℓ-κ}} f_{i||j}·x_{κ+1}^{j_1}·...·x_ℓ^{j_{ℓ-κ}} ∈ F_{q^k}
```

**Step 2**: Prover sends partial evaluations
- Send k partial evaluations y_i ∈ F_{q^k}
- Optimization: send only k-1 (verifier computes y_{0...0})
- Cost: (k-1)·k·log(q) bits

**Step 3**: Verifier checks consistency
```
Verify: y = ∑_{i∈{0,1}^κ} x_1^{i_1}·...·x_κ^{i_κ}·y_i
```

**Step 4**: Define combined polynomial over F_{q^k}
```
Let F_{q^k} = F_q[Z]/φ(Z) where φ irreducible of degree k
Define f' ∈ F_{q^k}^{≤1}[X_{κ+1},...,X_ℓ]:
f'(X_{κ+1},...,X_ℓ) := ∑_{i∈{0,1}^κ} f_i(X_{κ+1},...,X_ℓ)·Z^{∑_{t=1}^κ i_t·2^{t-1}}
```
Where f_i(X_{κ+1},...,X_ℓ) := ∑_{j∈{0,1}^{ℓ-κ}} f_{i||j}·X_{κ+1}^{j_1}·...·X_ℓ^{j_{ℓ-κ}}

**Step 5**: Evaluation claim over F_{q^k}
```
f'(x_{κ+1},...,x_ℓ) = ∑_{i∈{0,1}^κ} y_i·Z^{∑_{t=1}^κ i_t·2^{t-1}} ∈ F_{q^k}
```

**Step 6**: Apply generic transformation
- Now have (ℓ-κ)-variate polynomial over F_{q^k}
- Apply Section 3.1 transformation
- Results in (ℓ-κ-α+κ) = (ℓ-α)-variate polynomial over R_q

### 4.3 Communication Cost Summary
**Requirements**:
- Partial evaluations: (k-1)·k·log(q) bits
- Generic transformation: d·log(q) bits
- Total: (k-1)·k·log(q) + d·log(q) bits
- Better than generic: d·log(q) alone

### 4.4 Variable Reduction Comparison
| Method | Input | Output Variables | Cost |
|--------|-------|------------------|------|
| Generic (3.1) | ℓ vars over F_{q^k} | ℓ-α+κ vars over R_q | d·log(q) |
| Optimized (3.2) | ℓ vars over F_q, eval in F_{q^k} | ℓ-α vars over R_q | (k-1)·k·log(q) + d·log(q) |

**Key Insight**: Optimized method reduces κ more variables at cost of sending partial evaluations
